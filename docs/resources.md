# Resources (curated, by phase)

Free unless marked. Prefer depth on a few sources over skimming many.

## Phase 1 — RTL & SystemVerilog

- **HDLBits** (hdlbits.01xz.net) — hundreds of small Verilog exercises with an online checker. Do one set per session as a warm-up.
- **ChipVerify** (chipverify.com) — concise Verilog / SystemVerilog / UVM reference pages.
- Harris & Harris, *Digital Design and Computer Architecture, RISC-V Edition* — the bridge from your courses to RTL. (book)
- Cliff Cummings, *Simulation and Synthesis Techniques for Asynchronous FIFO Design* (Sunburst Design paper) — classic, read after p01.

## Phase 2 — Python & cocotb

- **cocotb documentation** (docs.cocotb.org) — quickstart, triggers, writing testbenches. Use the 2.x docs.
- *Python Crash Course* or the official Python tutorial — only the parts you need for tooling.

## Phase 3 — Methodology

- Spear & Tumbush, *SystemVerilog for Verification* (3rd ed.) — the standard book. Chapters on OOP, randomization, coverage. (book)
- **Verification Guide** (verificationguide.com) — SV/UVM/SVA examples.
- **EDA Playground** (edaplayground.com) — run UVM on commercial simulators in the browser (free account).
- **SymbiYosys** docs — open-source formal; start with the FIFO example.

## Phase 4 — RISC-V capstone

- *The RISC-V Instruction Set Manual, Volume I* — RV32I chapter only.
- **riscv-tests** (github.com/riscv-software-src/riscv-tests) — official ISA tests (rv32ui).
- **Verilator** user guide — C++ harness, `--trace-fst`, `--timing`.
